Version 10 - October 2026

  • Content changed to add hint text to group undertaking option. User research indicated a lack of understanding on this option. Changed to hopefully improve clarity.

  • The first statement for a corporate group has been changed. It initially said
    'I'm an officer or employee of a firm thats a group undertaking of NR1 TRADINGS LTD'.
    The following has been added to the end of the statement -
    'or an officer or employee of one of its corporate officers'
  • The first statement for a corporate officer has been changed from -
    I am an officer or employee of a corporate officer of NR1 TRADINGS LTD
    to
    I am an corporate officer (officer or employee) of NR1 Tradings ltd, or of a firm thats a group undertaking of NR1 trading

Version 9 - September 2026

  • New Policy requirements mean that group undertaking and judicial factor need to be added as possible roles. Content of radio options changed on roles page accordingly.

  • On statements page a new statement has been added to statement list confirming details displayed on screen are correct.

  • Hint text moved to Inset text

Version 8 - September 2026

  • Different versions of Role pages can be displayed dependent on information gathered from User sign in. For example we can tell if user is an ACSP and display options or leave them omitted accordingly
  • So different 'role page' scenarios have been added to the prototype. They are -
    • Scenario - ACSP doing a company filing
    • Scenario - Sole trader ACSP doing a company filing
    • Scenario - An ACSP doing an Individual filing
    • Scenario - A verified company officer/ employee doing a company filing
    • Scenario - A sole trader ACSP doing an Individual filing
    • Scenario - A verified individual doing an Individual filing
    • Scenario - An unverified company officer/ employee doing a company filing
    • Scenario - An unverified individual doing an Individual filing
  • New Policy requirements mean that ACSP email, name and number need to be displayed and checked for an ACSP filing, and name and DOB need to be displayed and checked for an individual filing.
  • A new summary table has been added to the statements page to show this information
  • Hint text added below header to improve user understanding

  • Multiple checkboxes have been reduced to one, with the multiple statements listed as a bulleted klist beside it. This change comes from user research showing users not being clear that all boxes needed ticking.

Version 7 - August 2026

  • Two new screens added fopr Presenters IDV project.

  • First new screen asks user which role they are filing as today. This information is required so we can tailor the statements on the second new screen

  • Second new screen displays a list of presenter statements that need to be agreed in order to proceed with filing

  • Both new screen are in the form of radio selects.
