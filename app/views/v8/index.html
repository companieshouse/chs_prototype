Changes this version

  • Different versions of Role pages can be displayed dependent on information gathered from User sign in. For example we can tell if user is an ACSP and display options or leave them omitted accordingly
  • So different 'role page' scenarios have been added to the prototype. They are -
    • Scenario - ACSP doing a company filing
    • Scenario - Sole trader ACSP doing a company filing
    • Scenario - An ACSP doing an Individual filing
    • Scenario - A verified company officer/ employee doing a company filing
    • Scenario - A sole trader ACSP doing an Individual filing
    • Scenario - A verified individual doing an Individual filing
    • Scenario - An unverified company officer/ employee doing a company filing
    • Scenario - An unverified individual doing an Individual filing
  • New Policy requirements mean that ACSP email, name and number need to be displayed and checked for an ACSP filing, and name and DOB need to be displayed and checked for an individual filing.
  • A new summary table has been added to the statements page to show this information
  • Hint text added below header to improve user understanding
  • Multiple checkboxes have been reduced to one, with the multiple statements listed as a bulleted klist beside it. This change comes from user research showing users not being clear that all boxes needed ticking.
